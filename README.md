## Pembaruan Versi 1080p (Scale 6x)
- **Scale:** Ditingkatkan dari  ke  (resolusi frame sprite meningkatkan 1.5x, mis.  dari  menjadi  piksel).

## Pembaruan Teknis
- **Upscale Semua Sprite:** Semua file sprite  telah di-upscale menggunakan algoritma edge-aware / anime HD (mis. Real-ESRGAN, waifu2x, atau xBRZ) dari resolusi 4x ke 6x total.
- **Dimensi Frame:** Setiap frame animasi sekarang memiliki resolusi 1080p (1056×1086 px untuk idle), memberikan detail yang sangat tajam untuk rambut, mata Sharingan, dan garis edges karakter.
- **Batas GPU:** Memastikan dimensi maksimum per sprite tidak melebihi  limit tekstur GPU Android.

## Cara Instalasi
1. Unduh atau buat arsip  berisi  beserta seluruh file sprite  yang sudah di-upscale 1.5x.
2. Buka **DSH-Go** → masuk ke menu **Pets → Import**.
3. Pilih file  tema ini, lalu pilih **Shisui Uchiha**.
4. Atur **Size = Large** untuk tampilan 1080p terbaik.
